Changes made for Ambient TV
The original SVG paths and affine transformations were converted to Android VectorDrawable resources with 64 x 64 viewports. The artwork uses the app theme color through tinting. The original icon shapes were preserved.
The Commodore 128 icon remains original Ambient TV artwork and is not part of this RetroArch asset import. No RetroArch theme fonts are included.
